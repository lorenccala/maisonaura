# Maison Aura

Standalone static website. The live maisonaura.al site has not been modified.

## Editing
- `dist/index.html`: business copy, sections, facilities and FAQs, editable directly as semantic HTML.
- `dist/style.css`: design tokens, responsive layout, typography and motion fallbacks.
- `dist/app.js`: enquiry destination, photographic scroll motion, gallery and mobile navigation.
- `dist/style-board.html`: editable identity/style board.
- `dist/assets`: original images and official logo recovered from the existing website.

Serve the dist directory using any static server. No dependency installation or build is required.

## Production notes
Direction: Adriatic stillness; ivory, olive and bronze; Cormorant Garamond and Manrope via Google Fonts, with local system fallbacks.
Photo motion only; no generated footage or synthetic property imagery. The hero source is 643×567 and can look soft on large screens. Replace it with a higher-resolution original when available.
